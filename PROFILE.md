# StayingAPI

Unified accommodation-data API returning live search, availability, price, cross-OTA price comparison, and normalized reviews across Airbnb, Booking.com, Vrbo, and Google Hotels via a single normalized JSON schema. Delivered over REST, a hosted MCP server, and a typed TypeScript SDK on one shared credit balance.

## APIs

- **StayingAPI REST API** — REST API with 8 endpoints (search, availability, listing, price, price-compare, reviews, account, jobs) returning normalized accommodation data. HTTP Bearer API-key auth; live scrapes return 202+jobId to poll. (`https://api.stayingapi.com/v1`)
- **StayingAPI MCP Server** — Hosted MCP server (Streamable HTTP, OAuth 2.1/PKCE) exposing 7 read-only tools mapping 1:1 to the REST endpoints: search_stays, check_availability, get_listing, get_price, compare_prices, get_reviews, get_job. (`https://mcp.stayingapi.com/mcp`)
- **StayingAPI Agent Skills** — Published portable SKILL.md agent skill in the stayingapi/travel-skills GitHub repo, referenced from the SDK docs, plus n8n workflow recipes. (`https://github.com/stayingapi/travel-skills`)
